    01Post-quantum security · Developer tool

    QuantumSafe Scan

    Scans code in 11 languages for the encryption quantum computers will break, scores the exposure from 0 to 100, and names the NIST-standard replacement for every finding.

    • Scan your code ↗
    • PyPI
    • Report
    • Source

    88%
    recall on held-out real code
    587
    tests in CI
    • Usage-aware detectionA hybrid AST-and-regex engine that ignores comments and code nothing calls, raising precision from 49.1% for naive matching to 100% on its benchmark.
    • Reads the TLS handshakeBuilds a TLS 1.3 ClientHello by hand to detect post-quantum hybrid key exchange, and checks every signature in the certificate chain, not just the leaf.
    • Demonstrates the threatShor's and Grover's algorithms run on the Qiskit simulator, and a lattice (LWE) key-encapsulation mechanism, the math behind ML-KEM, is written from scratch.
    • Built for real pipelinesPublished on PyPI and as a GitHub Action, with SARIF and CycloneDX CBOM export and a baseline mode that fails a build only on new findings.

    02Reinforcement learning · Research paper

    RL Trader

    A trading agent built on PPO written from scratch, and a paper archived with a DOI on how to tell an agent that learned from one that got lucky, with financial markets as a deliberately hard testbed.

    • Run the live lab ↗
    • Paper
    • Source
    30
    independent training seeds per experiment
    19 yrs
    of real SPY data in the option-hedging study
    506
    tests in CI
    • PPO from first principlesProximal Policy Optimization with generalized advantage estimation in PyTorch, over two custom Gymnasium environments with shared cost and accounting.
    • Pre-registered evaluationPredictions committed before the runs, an audit against Stable-Baselines3, leak-free splits, and walk-forward retraining across four periods of history.
    • Where it worksHedging a sold option, the agent learns to trade less as costs rise and beats a tuned textbook hedge at high costs on 19 years of real SPY data.
    • Generalization, measuredTraining on a fresh simulated market each episode lifts held-out return from −44% to +187% on crypto-like paths, with every confidence interval clear of zero.

    04Quantitative finance · Statistical validation

    AlphaGlyph

    A backtesting and forecasting lab that runs every strategy through the statistical tests quant funds use to separate genuine skill from luck.

    • Run a backtest ↗
    • Research lab
    • Report
    • Source
    106k
    parameter transformer forecaster
    512 MB
    server it runs in, served as ONNX
    337
    tests in CI
    • Skill versus luckProbabilistic and Deflated Sharpe ratios, combinatorial purged cross-validation, the probability of backtest overfitting, and Fama-French factor attribution.
    • A data-mining labGenerates hundreds of strategies with no edge by construction, then shows naive statistics calling the luckiest significant while the Deflated Sharpe calls it noise.
    • A calibrated forecasterA small multi-modal transformer that outputs an up-move probability, non-crossing q10–q90 return quantiles and a volatility forecast.
    • Lean servingTrained offline and shipped as ONNX, about 40 MB of runtime instead of PyTorch's 700 MB, with a forward ledger that grades live predictions.

    Python · Flask · pandas · SciPy · ONNX Runtime · Chart.js · Postgres
